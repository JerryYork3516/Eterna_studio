# Abstract Bust v0.2 · 视觉目标冻结 · C1

> `abstract_bust_v0_2` 的产品视觉目标与版本边界。本文件只冻结“应当呈现什么”，不定义实现方式、协议字段或确定性算法。

---

## 1. 视觉产品定位

`abstract_bust_v0_2` 定位为：

> 肩部或上胸以上、具有人形辨识度的抽象粒子肖像。

它必须能够在不进入写实人物范围的前提下，清楚区分：

- 基本头部轮廓；
- 抽象五官；
- 颈肩关系；
- 上胸轮廓；
- 发型；
- 年龄倾向；
- presentation 倾向；
- 不同居民之间的形体差异。

最终形象仍是抽象粒子生命体。人形辨识度来自体积、轮廓、层次和比例，而不是皮肤、纹理或写实器官。

---

## 2. 当前问题与 v0.2 改进方向

`abstract_bust_v0_1` 已完成工程链路，但其默认视觉结果存在以下产品问题：

- 头部过于接近标准球体；
- 颈部过长、过细；
- 肩部接近水平横梁；
- 躯干接近圆柱或方柱；
- 抽象五官辨识度不足；
- presentation、age_tendency 和发型之间的肉眼差异不足。

v0.2 必须针对这些视觉问题形成新的独立视觉基准。不得通过颜色、动画、材质、相机或后处理掩盖形体问题。

---

## 3. 默认形体目标

默认形体必须同时满足以下目标：

- 头部呈现可辨认的人类头颅轮廓，而不是标准球体或近似球体；
- 正面能够辨认额头、眼部区域、鼻部、嘴部、颧部和下颌的层次关系；
- 侧面能够辨认额头、鼻部突出、嘴部、下巴和后脑轮廓；
- 颈部长度适中，宽度能够自然连接头部和肩部；
- 肩部具有自然斜率，不出现水平横梁或尖锐末端；
- 上胸与肩部连续过渡，不呈圆柱、方柱或孤立块体；
- 头、颈、肩和上胸共同形成连续、稳定的人形剪影；
- 默认 neutral 形体不明显偏向男性或女性。

任何单独视角成立、但在其他视角出现断裂、穿插或非人形轮廓的结果，均不满足默认目标。

---

## 4. 抽象五官边界

### 4.1 允许的表达

- 粒子密度变化；
- 局部凹凸；
- 轮廓层次；
- 抽象眼部带；
- 抽象鼻部体积；
- 抽象嘴部曲线；
- 抽象颧部和下颌。

五官用于建立人形辨识与居民差异，不要求写实精度，也不承担表情动画。

### 4.2 禁止的表达

- 真实眼球；
- 真实嘴唇；
- 牙齿；
- 皮肤；
- 纹理贴图；
- 写实毛发；
- 表情 BlendShape；
- 骨骼和肌肉系统。

---

## 5. presentation 视觉差异

`neutral`、`feminine` 和 `masculine` 必须能够肉眼区分，但不得依赖服装、颜色或刻板化特征。

差异主要通过以下形体关系表达：

- 头脸比例；
- 下颌形态；
- 颧部轮廓；
- 颈部比例；
- 肩部宽度与斜率；
- 上胸轮廓。

`neutral` 是均衡基准；`feminine` 与 `masculine` 是克制的形体倾向，不定义居民的性别身份，也不得触发 Blueprint 之外的隐藏语义。

---

## 6. age_tendency 视觉差异

`youthful`、`balanced` 和 `mature` 必须可区分，同时保持克制。

差异主要通过以下形体关系表达：

- 头脸比例；
- 轮廓圆润度；
- 下颌和颧部的明确程度；
- 五官区域比例；
- 颈肩稳定感。

年龄倾向只描述视觉轮廓，不表示居民真实年龄。禁止使用皱纹、皮肤老化或其他写实年龄特征。

---

## 7. 发型视觉目标

`none`、`short`、`medium`、`long` 和 `tied` 必须形成可辨认的不同外轮廓。

发型只表现为抽象粒子体积：

- 不生成单根发丝；
- 不定义发色；
- 不实现物理动画；
- 不引入材质；
- 不得遮挡到无法辨认主要五官和头部轮廓。

发型体积必须与头部和颈肩关系协调，不得成为与头部脱离的独立粒子块。

---

## 8. Studio 与 Aftelle 职责

### 8.1 Studio

Studio Visual Builder 负责：

- 定义默认形体；
- 定义 Preset；
- 定义视觉语义；
- 形成居民最终 Blueprint；
- 冻结并交付 v0.2 的 Schema、Fixture、生成器与 Golden。

Studio 是 v0.2 形体视觉目标和居民 Blueprint 的决定方。

### 8.2 Aftelle

Aftelle 负责：

- 按 `generator_version` 选择兼容实现；
- 根据完整 Blueprint 重建对应形体；
- 在形体协议之外负责 Morph、动画和特效；
- 在收到 Studio 的完整 v0.2 交付包后实现兼容 Runtime Adapter。

Aftelle 不反向定义 Studio 的默认形体、Preset 或居民视觉语义。

## 9. 当前不属于 v0.2 形体目标的内容

以下内容不属于 C1，也不得混入 v0.2 的形体视觉目标：

- 粒子颜色设计；
- 情绪颜色；
- 呼吸；
- Morph；
- 流动；
- Thinking / Speaking 动画；
- 表情动画；
- 服装；
- 材质；
- 全身；
- 写实人像；
- 二次元形象；
- AR 场景；
- 相机状态；
- 粒子坐标持久化。

这些内容即使在后续阶段存在，也不能改变本文件冻结的形体判断标准。

## 10. 版本边界

### 10.1 abstract_bust_v0_1

- 永久冻结；
- 不修改算法；
- 不修改 Fixture；
- 不修改 Golden；
- 继续支持旧 DR。

任何视觉改进不得以静默修改 v0.1 的方式实现。

### 10.2 abstract_bust_v0_2

- 由 Studio 定义；
- 后续拥有独立的 Schema、Fixture、生成器和 Golden；
- Aftelle 在收到完整交付包后实现兼容 Runtime Adapter；
- 不覆盖或替换 v0.1 的历史契约与旧 DR 支持。

- PRNG；

## 12. 最小人工验收清单

后续 v0.2 实现至少需要人工确认：

- [ ] 正面能辨认人形五官与头颈肩结构；
- [ ] 侧面能辨认鼻部、嘴部、下巴和后脑；
- [ ] 三分之四视角轮廓连续；
- [ ] 默认形体不再是球体、长颈和柱状躯干的组合；
- [ ] 三种 presentation 可区分；
- [ ] 三种 age_tendency 可区分；
- [ ] 五种发型可区分；
- [ ] 不同参数能够形成居民专属轮廓；
- [ ] 整体仍保持抽象粒子视觉。

C1 只冻结以上文本标准，不要求截图、录屏、视觉对比实验或反复调参。
